# Weekly news analysis agents — status

The scheduled path exists and is wired as:

`news_daily_pipeline` → `analysis_l8_daily_generation` →
`WeeklyAnalysisGenerator` → JSON dashboard export.

On Fridays the L8 DAG calls `generate_for_week`; the LangGraph graph has four
parallel domain agents (technical, news, macro and FX) plus a reflection
synthesizer. Daily and weekly statistical digests are also generated by the
NewsEngine DAGs.

Important production qualification: LangGraph enrichment is currently
best-effort/non-blocking. Missing dependencies or agent errors are swallowed and
the baseline export remains valid. The L8 path writes dashboard JSON; database
`weekly_analysis`/`daily_analysis` persistence and live LLM/provider execution must
be verified in the deployed Airflow/PostgreSQL environment. Therefore agents are
implemented and schedulable, but not yet certified as healthy production runs.
